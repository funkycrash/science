Le mode sombre est-il meilleur pour les yeux ?

Non, le mode sombre n’est pas meilleur pour les yeux, il est même moins bon que le mode clair. Plusieurs études ont mesuré la différence d’acuité visuelle entre le mode sombre (écriture blanche sur fond noir) et le mode clair (écriture noire sur fond blanc). L’une d’entre elles, publiée dans la revue Ergonomics en 2014, montre par exemple que nous lisons moins rapidement et que nous distinguons moins bien les petits caractères avec le mode sombre. Cette différence est induite par la taille de notre pupille (petit orifice noir au centre de l’oeil). Sur un écran noir, la pupille s’agrandit pour capter plus de lumière, ce qui entraîne un phénomène « d’aberration sphérique » : comme les phares des voitures dans la nuit, les lettres blanches forment un petit halo lumineux sur l’ensemble du texte. La lecture devient plus floue et moins agréable.
